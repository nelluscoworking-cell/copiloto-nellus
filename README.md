# Nellus Copiloto Comercial V18

Substitua os arquivos do projeto no GitHub pelos arquivos desta pasta e faça um novo deploy na Vercel.

V18 adiciona o mecanismo de Próxima Ação Comercial: depois de responder, o Motor Nellus procura uma pergunta estratégica para manter a conversa avançando, de acordo com a etapa e o tipo de solicitação.

Também mantém o treinamento local e remove emojis das mensagens comerciais geradas.

Arquivos: index.html, manifest.webmanifest, service-worker.js, vercel.json e icons/.
